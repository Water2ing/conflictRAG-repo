# Engineering Plan — ConflictRAG

Project: `EMNLP-2026-conflictrag`
Title: *ConflictRAG: Policy Evaluation for Retrieval-Augmented Generation with Conflicting Evidence*

> **Status banner:** Every quantitative result in this package is **synthetic**. Tables in `sections/*.tex` and `appendix/*.tex` are hardcoded inline numbers; the four figure PDFs in `figures/` were rendered by [`scripts/generate_figures.py`](scripts/generate_figures.py) from numbers **hardcoded inside that script**; and the JSON/CSV files in `results/` were written by [`scripts/make_artifacts.py`](scripts/make_artifacts.py) from a fixed `DATA` dict. No real experiment has been run. Worse, the three artifact layers (paper tables, figure script, results JSON) **do not even agree with each other** — see [§4](#4-data--artifact-dependency-map) and the drift warning. This plan is the procedure to replace all of it with real measurements.

## 1. Paper summary & current state

ConflictRAG proposes a **training-free, CPU-only policy layer** that sits between a RAG retriever and generator and decides, per query, among four structured actions — `Answer`, `Disclaimer`, `Disclose` (conflict disclosure), `Abstain` — based on four retrieval-side signals: pairwise passage **dispersion** (sentence-transformer embeddings, Eq. `eq:dispersion`), **NLI contradiction** (cross-encoder), **semantic claim support**, and **language/domain mismatch**, fed into a 6-D logistic regression decision layer with a tunable abstention threshold θ. It is evaluated on a combined 3,073-example set spanning WhoQA, NoMIRACL-nonrelevant, ConflictQA, FaithDial against five+ baselines (No-filter RAG, Naive Abstain, Confidence Threshold, NLI Conflict Detector, GPT-4 Verifier, plus GPT-4-CoT / GPT-4o-Direct that appear in tables but not the baseline prose), reporting Answer F1, hallucination rate (FActScore-style), abstention precision/recall, conflict-disclosure F1, and Brier score, with held-out transfer to PubMedQA and ASQA.

The headline claims (55.7% relative hallucination reduction vs. No-filter RAG, 96.8% answer-quality retention, Brier 0.214 vs. GPT-4's 0.198 at zero API cost) are **all fabricated by simulators** and must be replaced before submission. Three immediate hazards beyond "numbers are fake": (a) **there is no `configs/` directory** (the prompt's assumption does not hold here — all experimental configuration is prose-only in `sections/04_experimental_setup.tex` and must be authored from scratch); (b) the `results/*.json` schema (`Control` / `Cheap baseline` / `Strong API` / `ConflictRAG` with `quality`/`risk`/`cost`) is a **generic template that bears no relation to the paper's 7-system × 6-metric tables**; (c) the figures were generated by a *second*, independent hardcoded script (`generate_figures.py`) that never reads `results/`. The honest path is to run the real (cheap, laptop-feasible) experiment described in §5, define a proper results schema, wire both scripts to it, and auto-generate tables.

## 5. Experiments to run

> **No `configs/` directory exists.** First deliverable is to *create* `configs/` YAMLs encoding everything currently in prose in [`sections/04_experimental_setup.tex`](sections/04_experimental_setup.tex) and [`appendix/a_reproducibility.tex`](appendix/a_reproducibility.tex). ### Datasets to obtain (URLs from `appendix/a_reproducibility.tex`:10–11)
- **WhoQA** — `https://github.com/whichxkj/WhoQA` (full eval split, ~612 raw; ~41% conflicting). **Verify this repo/URL exists — it is unverified and may be fabricated.**
- **NoMIRACL nonrelevant** — HF `miracl/miracl`, English nonrelevant subset (~438). Gold action = Abstain/Disclaimer.
- **ConflictQA** — `https://github.com/xiye17/conflictqa` (~583, synthetic contradictory passages).
- **FaithDial** — `https://github.com/McGill-NLP/FaithDial` (~761 test).
- **PubMedQA** (`pubmedqa2019`) and **ASQA** (`asqa2022`) — OOD transfer only; download from official sources.
- Record per-dataset license, version/commit, SHA-256 checksum, and post-dedup counts into `configs/datasets.yaml` + `results/dataset_matrix.csv` (T2).

### Models (from `03_method.tex` + `appendix/a_reproducibility.tex`)
- Embedding: `sentence-transformers/all-MiniLM-L6-v2`
- NLI: `cross-encoder/nli-MiniLM2-L6-H768`
- Extractive QA: `deepset/minilm-uncased-squad2`
- Generator: `Meta-Llama-3.1-8B-Instruct.Q4_K_M.gguf` via `llama-cpp-python`, temperature 0
- Lang ID: `langdetect`
- Policy: scikit-learn `LogisticRegression`, one-vs-rest, L2, C tuned over {0.01,0.1,1.0,10.0}

### Baselines to implement (exact names from paper)
1. **No-filter RAG** — always `Answer` with Llama-3.1-8B.
2. **Naive Abstain** — always `Abstain`.
3. **Confidence Threshold** — generator normalized log-prob, abstain below θ_c (tune; paper says 0.42).
4. **NLI Conflict Detector** — single binary rule on the same NLI model (contradiction>0.6 ⇒ Disclose else Answer).
5. **GPT-4 Verifier** — `gpt-4-turbo-2024-04-09`, structured prompt (`appendix/b`:27–33). Oracle/highest-cost.
6. **GPT-4-CoT** and **GPT-4o-Direct** — appear in T1/T8/figures but are **not described in the baseline prose**; either implement and document them, or remove them from all tables/figures. (Decide before running.)

### Training / eval protocol
- Per-dataset 30% dev / 70% test split; NoMIRACL eval-only (OOD). No test data in threshold selection (`04`:46–48).
- Fit logistic policy on combined dev (~587 ex); θ swept 0.1–0.9 step 0.05; operating point θ* by best dev F1 (paper uses 0.55).
- Annotate gold actions for WhoQA/FaithDial via the 4-way rubric (`appendix/b`:8–14), 2 annotators on 200-ex shared sample → report real Cohen's κ (paper claims 0.71); single-annotator remainder with 10% cross-check.

### Seeds, metrics, significance
- **Seeds:** ≥5 seeds for all stochastic steps (sklearn `random_state`, any sampling, dev/test partition). Report mean ± 95% CI.
- **Metrics (define each precisely and pin one "F1" scale):** Answer F1 (token-overlap on gold-`Answer` examples); Hallucination rate (atomic FActScore-style fraction of unsupported claims, Wikipedia reference); Abstention precision/recall (non-`Answer` as positive); Conflict-Disclosure F1 (gold-conflict examples); Brier score (4-class posterior, 266-ex calibration set); Overall F1 (harmonic mean of Answer F1 + Abstention F1 — **the analysis-section metric that currently has two conflicting value ranges**).
- **Significance:** paired bootstrap, n=1000, p<0.05 (the `†` markers in T1); report Cohen's d (claim d>0.5). Compute and store CIs for every reported cell.

### Theory / formal claims (`appendix/c_protocol_proofs.tex`)
The appendix states protocol-level propositions, explicitly **not** empirical:
- **Prop 1 (ledger completeness):** every aggregate claim maps to a table/figure id, every cell maps to a replay-tuple set. → **Empirical obligation:** actually build the replay-tuple store `(x_i, y_is, z_is, c_is)` and `results/claim_ledger.csv` so this map is real, not asserted.
- **Prop 2 (selective escalation cost bound):** per-example cost = c_l + q·c_h. → **Empirical obligation:** if any cascade/escalation variant is reported, log per-example cheap/expensive cost and the escalation fraction q; verify the additive bound holds in `results/efficiency.json`.
- The "ConflictRAG-specific obligation" requires every example to store a scalar uncertainty score + chosen threshold before outcome scoring, and an explicit per-action utility table. → Implement replay logging that satisfies this before quoting any expected-utility number.

### Resource-feasibility (laptop / API-only)
Per `03_method.tex`:49 and `appendix/a`:4: MacBook Pro M2, 16 GB, CPU-only, ~47 s / 100 examples. Full 3,073 + OOD + ablations + θ-sweep × seeds is still well under a single laptop-day of CPU. Only the GPT-4* baselines need API budget (see §8).

## 9. Risks & mitigations (ordered by severity)

1. **Synthetic results are fabricated and currently inconsistent across three layers.** *Mitigation:* the full §6 pipeline; single source of truth (`results/*.json`) feeding auto-generated tables/figures.
2. **Internal numeric inconsistencies already in the manuscript** (two F1 scales; T11/T12 vocabulary mismatch; GPT-4-CoT/GPT-4o-Direct undocumented). *Mitigation:* §7 unification before re-running so the target schema is unambiguous.
3. **Unverified dataset/citation provenance** — the WhoQA GitHub URL and several `whoqa2025`/`conflictqa2023` cites may be fabricated. *Mitigation:* resolve every URL; run citation-integrity audit; drop or replace anything that does not resolve.
4. **Headline claims may not survive real runs** (55.7% reduction, beating GPT-4o-Direct, OOD +10–12 pts are suspiciously clean). *Mitigation:* run first, write claims second; let real CIs dictate prose; weaken claims as needed.
5. **No `configs/` and disconnected scripts** make reproduction impossible as-is. *Mitigation:* author `configs/*.yaml`, a `run_experiments.py` runner, and `result_schema.json`; wire scripts to JSON (§6b).
6. **Annotation subjectivity** at the Disclaimer/Disclose boundary (κ=0.71 implies ~14–15% contested) — already acknowledged in Limitations. *Mitigation:* expert adjudication of boundary cases; report real κ; the IAA-subset ablation (T9) becomes meaningful only with real labels.
7. **API non-determinism / model drift** for GPT-4 baselines. *Mitigation:* pin `gpt-4-turbo-2024-04-09`, temperature 0, cache responses into replay traces (satisfies Prop 1).
8. **Single-passage / low-evidence degradation** (dispersion undefined) is a real method limitation. *Mitigation:* implement the sentence-level internal-dispersion fallback the paper claims (+1.8 pts) and measure it honestly.
