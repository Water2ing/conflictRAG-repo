\section{Summary}

The 4D run tested whether the policy still works once passage count $k$ and query length are
removed from its inputs. It does not yet support the paper's central claim.

\begin{itemize}
\item \textbf{The 4D policy is no better than counting passages.} It reaches 0.602 macro-F1 on
  the test set. A fixed rule that uses only $k$ ($1\!\to$\,ANSWER, $2\!\to$\,DISCLOSE,
  $3\!\to$\,ABSTAIN) reaches 0.665, and a logistic regression on $k$ and query length reaches 0.605.
\item \textbf{The ablation looks clean but is misleading.} Removing any feature lowers macro-F1
  significantly, yet three of the four features act as indicators of passage count or source
  dataset, not as the signals the paper describes.
\item \textbf{DISCLAIMER is not learnable} from these features (F1 0.105), and performance drops
  sharply on the two sources absent from dev (accuracy 0.572 vs.\ 0.778).
\item \textbf{The baselines are too weak to carry the comparison.} Neither ever predicts DISCLOSE,
  and both have lower accuracy than always answering.
\item \textbf{Generation was deliberately not run.} The study evaluates the routing decision;
  Llama 3.1 was not connected, so only routing decisions are reported.
\end{itemize}

The root cause is the benchmark: source and passage count nearly determine the label. Removing
$k$ from the inputs did not remove the shortcut, because dispersion and NLI contradiction are
exactly zero whenever $k=1$.

\section{Setup}

\textbf{Policy.} One-vs-rest logistic regression on
[dispersion, NLI contradiction, claim support, mismatch], with a gate $\theta$ on $P(\mathrm{ANSWER})$.
Trained on \code{dev\_set\_natural.jsonl} (1{,}000 examples); evaluated once on
\code{test\_set\_1.jsonl} (3{,}073 examples).

\textbf{Hyperparameters.} A joint grid search with 5-fold stratified CV on dev covered 18{,}480
configurations. The best was $\tau_s{=}0.3$, TF-IDF${=}0.20$, $C{=}1.0$, $\theta{=}0.40$, with mean
fold macro-F1 0.686 $\pm$ 0.029. TF-IDF sat on the grid edge, so the range was extended to
0.18--0.50 (15{,}120 configurations); the optimum did not move. Only 21 of the 18{,}480
configurations are within 0.01 of the best.

\textbf{Evaluation.} Each ablation variant retrains on dev and re-tunes $\theta$ on out-of-fold dev
predictions. Differences use a paired bootstrap on the test set ($B{=}1000$).
Environment: scikit-learn 1.5.1, transformers 4.44.2, sentence-transformers 3.0.1, torch 2.4.1.

\textbf{Against the shortcut.} The 4D policy trails the $k$-only rule by 0.064 macro-F1
(95\% CI $-0.081$ to $-0.047$) and is indistinguishable from $k$ + query length
($+0.004$, $p{=}0.74$). If DISCLAIMER is merged into ANSWER, the gap widens: 0.816 for the policy

DISCLOSE by design, the Vanilla router never chose it, and both score 0.000 accuracy on ConflictQA.

\textbf{4D vs.\ 6D.} Dropping $k$ and query length costs 0.041 macro-F1
(95\% CI $-0.056$ to $-0.025$) but raises accuracy by one point. The two models agree on 84\% of

\begin{itemize}
\item \textbf{Dispersion is a passage-count flag.} It is exactly 0 for all 1{,}831 single-passage
  examples and never 0 otherwise. That is why removing it costs 0.148. Among multi-passage
  examples it does not separate DISCLOSE from the rest (AUROC 0.48). It does carry real signal
  within WhoQA (AUROC 0.89 for DISCLOSE vs.\ ANSWER), which the trained policy fails to use.
\item \textbf{NLI contradiction points the wrong way.} It is lowest on ConflictQA, where every
  example is a conflict (mean 0.013), and high on irrelevant-passage sets. For DISCLOSE vs.\ the
  rest among multi-passage examples its AUROC is 0.18. The policy uses it as an ABSTAIN cue:
  removing it lowers NoMIRACL accuracy from 0.746 to 0.462, leaves DISCLOSE F1 almost unchanged,
  and \emph{raises} WhoQA accuracy from 0.373 to 0.767.
\item \textbf{Mismatch is a source flag.} It fires on 93--96\% of FaithDial and 97--100\% of WhoQA,
  but on only about 30\% of the truly irrelevant NoMIRACL and RGB examples.
\item \textbf{Claim support behaves as intended.} Low support goes with ABSTAIN (AUROC about 0.78).
\item \textbf{DISCLAIMER cannot be separated.} All 301 DISCLAIMER cases have $k{=}1$, where the
  feature vector takes only four distinct values. The DISCLAIMER rate in those four cells is
  11--19\%, against 16\% overall. The policy assigns DISCLAIMER to one cell of 225 examples, of
  which 28 are correct (12\%), which is below the base rate.
\item \textbf{DISCLAIMER labels describe the response, not the evidence.} They come from the
  ``Generic'' and ``Uncooperative'' response tags in FaithDial and the ``maybe'' decision in
  PubMedQA. No retrieval-side feature can be expected to recover them.
\end{itemize}

\section{Reliability and reproducibility issues}

\begin{itemize}
\item \textbf{Generation out of scope by design.} Llama 3.1 was intentionally not connected, so
  2{,}567 outputs carry the \code{GENERATION\_ERROR} placeholder and 506 the fixed ABSTAIN string.
  The routing decisions are unaffected. Answer quality and hallucination rate are not measured,
  so the paper should not claim them.
\item \textbf{$\theta$ is fragile.} On dev, mean fold macro-F1 is 0.686 at $\theta{=}0.40$,
  0.676 at 0.45, 0.548 at 0.50, and 0.478 from 0.55 upward.
\item \textbf{Config synced (14 Nov 2026).} \code{framework/config.py} previously held
  0.2 / 0.10 / 10 / 0.50; it now holds the values the run used, 0.3 / 0.20 / 1.0 / 0.40.
\item \textbf{Two 6D reference files disagree.} The \code{\_results\_final} file gives 0.642
  macro-F1. An older 6D file in the root \code{results/} folder
  (\code{test\_set\_1\_results.json}), used in the collaborator's report, gives 0.633. One must
  be designated as the reference.
\item \textbf{Language detection is unseeded.} The collaborator's rerun found the mismatch feature
  changed on 7 test examples between runs; this rerun's files are not in the repository, so it
  is unverified here.
\item \textbf{Minor overlap.} 9 of 1{,}272 FaithDial test examples share an identical passage with
  a dev example.
\item \textbf{The test set is no longer untouched.} It has now informed design decisions,
  including dropping $k$ and query length.
\end{itemize}

\section{Implications for the paper}

Several statements in the guiding draft cannot be kept. ``Training-free'' is inaccurate, since
the policy is trained on 1{,}000 labelled examples. Dispersion as ``a reliable proxy for conflict''
and NLI as the driver of conflict disclosure are contradicted by Section~4. The draft's
human-annotation protocol, GPT-4 baselines, hallucination and Brier metrics, and out-of-domain
gains have no counterpart in the experiments so far.

\section{Recommended next steps}

\begin{enumerate}
\item \textbf{Rebuild the benchmark} so that passage count and source cannot predict the label:
  fix $k$ for every example and make each source contribute at least two labels. Create a fresh
  test split and leave it untouched until the end.
\item \textbf{Decide what DISCLAIMER means.} Either redefine it from the evidence (on-topic passage
  that lacks the answer) or reduce to three actions.
\item \textbf{Revisit the features on dev only.} Candidates: agreement between answers extracted
  from each passage in place of passage-level NLI, a continuous question--passage similarity in
  place of the binary mismatch flag, and the QA model's no-answer score.
\item \textbf{Fix the pipeline before rerunning.} Seed language detection, sync \code{config.py},
  add a routing-only mode that skips generation explicitly, and choose one 6D reference file.
\item \textbf{Strengthen baselines and controls.} Always report majority class, the $k$-only rule
  and $k$ + query length. Add a few-shot LLM router, an NLI-threshold rule, and a fine-tuned
  small classifier as an upper bound.
\item \textbf{Run the remaining analyses.} Calibration (Brier, ECE, risk--coverage),
  leave-one-source-out, a learning curve over dev size, hyperparameter sensitivity from the saved
  grid, and CPU latency.
\item \textbf{Rename the method and cite Wang et al.\ (2026)}, arXiv:2605.17301, which already
  uses the name ConflictRAG.
\end{enumerate}
